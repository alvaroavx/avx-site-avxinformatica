# Estado y alcance

## Objetivo observable

El prototipo busca presentar a AVX como partner tecnológico. La implementación actual cubre solo el primer banner.

## Implementado

- Menú horizontal con inicio, servicios, portafolio, partners, testimonios y contacto.
- Logo central, fondo, fuentes locales y propuesta de valor.
- CTA circular `Más`.
- Configuración Angular para desarrollo, build y pruebas.
- Receta Docker con Nginx y borrador Kubernetes.

## Intención no implementada

Los enlaces `/#servicios`, `/#portafolio`, `/#partners`, `/#testimonios` y `/#contacto` no tienen elementos con esos IDs. No existen páginas, rutas o componentes equivalentes. El CTA también apunta a `/#servicios`.

No hay catálogo real, casos, testimonios, formulario, correo, cotizador, datos, API, CMS, usuarios, pagos o administración.

La historia termina en febrero de 2022. Eso permite clasificarlo como intento histórico, no como fuente vigente sin una decisión posterior.
